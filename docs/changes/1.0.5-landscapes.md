# 1.0.5 — Shared hillside landscape design

The Android/web game has three zone builders: village, open_world, and dungeon
(the dungeon has forest and fire variants selected by tier).

- Village keeps its 800 full-size PBR homes and 20 scattered merchants.
- Open world has continuous bank slopes, a visible riverbed, a level bridge,
  four irregular trails, 46 PBR buildings, 175 trees and 115 rocks.
- Forest dungeon has sloping trails, seven PBR structures, 112 trees and 67 rocks.
- Fire dungeon uses existing volcanic/ember materials, 12 PBR structures,
  11 trees and 127 rocks, with a warm lighting/fog palette.
- Procedural structures avoid trail corridors, portal approaches, the river and
  the boss arena. Architecture stays upright and uses existing materials.
- Character, ally, enemy and portal elevations follow terrain. Movement bounds
  match each map. Expanded maps show routes, structures, landmarks and gate labels.
- No new shops were added to combat maps; the safe village remains the market.

Validation:
`node Tools/test_hillside_village.cjs`
`node Tools/test_world_landscape.mjs`
`python Tools/verify_apk.py artifacts/releases/WarriorsOfPersia_1.0.5.apk`

APK v1/v2 signatures and Android aapt2 checks pass. No physical Android device
or visual browser playtest was available. Unity/Godot sources and old standalone
HTML exports were not regenerated; this release bundles current web sources.
