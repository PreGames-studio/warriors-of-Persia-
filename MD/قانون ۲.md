# قانون ۲ — خروجی پیش‌فرض فقط APK

از این به بعد، هر موقع کاربر «خروجی بده» یا درخواست معادل آن را مطرح کند، فقط نسخه‌ی **APK** ساخته و ارائه شود.

## الزامات

- ساخت نسخه‌ی HTML و ZIP به‌صورت پیش‌فرض انجام نشود.
- نسخه‌ی HTML و ZIP فقط زمانی ساخته شوند که کاربر صریحاً و جداگانه درخواست کند.
- به‌روزرسانی و آماده‌سازی خروجی نیز به‌طور پیش‌فرض فقط شامل APK است.

این قانون برای همه‌ی خروجی‌های بعدی بازی معتبر است، مگر اینکه کاربر درخواست دیگری بدهد.
